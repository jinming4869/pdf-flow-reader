# 中日文 TTS 集成决策

## 保留英文链，新增共享 CJK 链

英文继续使用稳定的 `kokoro-js` worker；中文和日文共用一个 v1.0 int8 CJK worker。这样可以缩小英文回归面，并复用中日文模型资源。

## 语言提示与文字脚本共同路由

显式 `ja`、`zh` 和英语提示优先；缺少明确提示时，以假名识别日文、以汉字识别中文、以拉丁文字识别英文。纯汉字日文标题仍可能需要页面级语言信息。

## 使用 NDJSON 控制协议

短朗读单元通过 stdout NDJSON 返回 WAV base64，避免临时音频文件和路径竞态。若未来朗读单元显著增长，再考虑长度前缀二进制协议。

## 父进程持有取消边界

父进程负责请求队列、超时、worker 终止与临时目录清理。这样即使子进程被强制终止，也不会依赖其 `finally` 完成资源回收。

## 发布资源必须可审计

正式包使用锁定依赖、固定模型地址和 SHA-256，并携带自包含运行时。开发虚拟环境不得直接作为发布资源。
