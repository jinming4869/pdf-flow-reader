# v4.1 书架与开书动画

状态：**本机基线已验收，未公开发布**

验收日期：2026-08-09

## 目标

在不混入任何 v5 航迹数据模型的前提下，把最近阅读入口整理成可复用的书架宿主，为 v5.0 单书航迹和后续分析提供稳定入口。

## 范围

- 最近阅读与“打开新书”组成循环书架；
- 左右按钮、卡片点击、键盘方向键、Home、End、Enter 与 Space；
- “取下这本书”和“另取新书”的开书动作；
- 确定性书封配色、阅读进度、页码和阅读档位；
- 减少动画模式；
- 桌面包静态资源登记。

不包含：航迹、套索、情绪坐标、AI、归档或 PDF 内容身份迁移。

## 已知行为

1. 默认 1180 × 860 窗口中，书架动作行位于首屏下方约 47px；用户可以轻微滚动，或直接使用 Enter 取书。该项属于后续本机视觉微调，不阻塞基线。
2. v4.1 最近阅读记录只保存元数据。继续阅读历史 PDF 时仍需重新选择原文件；v5.0 的内容身份与路径恢复层将解决此限制。
3. 本检查点不修改 `package.json` 的公开版本号，也不创建 tag、PR 或 release。
