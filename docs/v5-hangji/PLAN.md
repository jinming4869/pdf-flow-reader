# v5「航迹」执行计划

状态：等待工程 PoC；各阶段必须先建立失败测试，再接入界面。

## 0. 建立干净基线

- 收口并独立处理 v4.1 书架 / 开书动画，不让未发布 UI 提交与 v5 数据模型混成一个变更。
- 更新项目记忆文件，明确 v4 已发布能力、v5 规划能力与非目标。
- 为真实普通 PDF、双栏论文、扫描书和大型 PDF 固定验收样本。

## 1. 阅读痕迹数据模型

- 定义 `ReadingTrace`、情绪坐标、AI 状态、裁图引用、归档状态和 schema version。
- 使用 PDF 指纹、页码、归一化路径、原文与上下文共同锚定。
- 实现原子写入、损坏恢复、删除、迁移和按文档查询。
- AI 字段与核心记录分离，确保失败和迟到结果不能覆盖用户数据。

## 2. 自由套索与高清裁图

- 套索入口暂停滚动、TTS 与入流曲线，同时冻结视口。
- 实现带采样、平滑、闭合和归一化坐标的自由路径。
- 以高质量页面 canvas 或可重渲染页面生成清晰裁图，并正确处理 DPR、缩放和旋转。
- 从路径覆盖区域取得原生文字或 OCR；不把页面外 UI 截入图片。
- 第一版限定同一页面，跨页手势给出温和反馈而不生成错误裁图。

## 3. 情绪坐标与最小暂停界面

- 实现连续效价 × 唤醒平面、键盘操作、减少动画与屏幕阅读器说明。
- 保存连续坐标；情绪名称只从邻域派生。
- 套索完成后的界面只呈现复述槽位、坐标盘和“回到书流”。
- 确保截图先保存，关闭窗口或 AI 失败也不丢失痕迹。

## 4. 手动回流与入流曲线

- 区分短中断、新书和长时间暂停。
- 短中断采用约 30 秒、新书或长暂停采用约 90 秒 smoothstep / 等价缓动。
- 目标保持在当前档位上部并预留边界余量；不自动跨档。
- 用户滚动、调速、暂停、换页、换文档或切档立即取消曲线。
- 记录入流前后速度用于痕迹与诊断，但不制造倒计时压力。

## 5. 单本书情绪航迹

- 在书架菜单展示二维散点与阅读顺序 / 页码。
- 点击坐标打开截图、复述和当时状态，并能跳回原页。
- 区分“用户情绪”与“AI 复述”，不让摘要替用户解释感受。
- 支持删除、修正坐标和重试等待中的一句复述。

## 6. 高频一句复述

- 定义短文本 `TraceEchoProvider` 和严格的一句复述 Prompt。
- 输入优先使用圈选区域文字，并提供必要的附近上下文；默认不上传整张截图。
- 目标健康网络下 1–3 秒返回；设置短超时、取消、去重和有界重试。
- 断网或失败保留 `pending / unavailable`，在用户已经授权 provider 后联网补生成。
- 本地小模型与在线快速模型共享输出契约，不影响核心数据格式。

## 7. 归档适配器

- 本地专用文件夹保存可检查的图片、Markdown 与 JSON。
- Obsidian 使用附件目录、Markdown 链接和稳定 frontmatter。
- Zotero 支持关联已有条目或导入当前 PDF，并把确认后的截图、页码、复述与情绪数据写入笔记。
- 每本书设置一次默认目的地；失败进入可重试队列，不阻塞套索或回流。

## 8. 书架中的重型认知任务

- 定义 `BookAnalysisProvider`，从一个 OpenAI-compatible API 开始。
- 提供分析、全文总结和 LSE 阅读 Worksheet；多书时提供融贯。
- Prompt 从安全的版本化 catalog 读取，不从 Zotero `prefs.js` 读取。
- 用户显式触发并看见将发送的文本范围、模型与估计等待；结果与书、版本、Prompt 和 provider 元数据关联。
- API 密钥进入操作系统凭据存储，日志、诊断和导出中始终脱敏。

## 9. 集成与发布验收

- 自动化覆盖套索几何、坐标映射、原子保存、AI 迟到、回流取消、情绪图和导出重试。
- 真实 PDF 覆盖文字页、扫描页、双栏、旋转页和大型文档。
- 验证套索时无旧 TTS、页面不漂移，回流不跨档且不与用户操作竞争。
- 离线完成完整“套索—情绪—回流—回看”路径；在线只增加回声和书架分析。
- macOS 与 Windows 包验证凭据存储、文件权限、归档路径和 provider 失败降级。
