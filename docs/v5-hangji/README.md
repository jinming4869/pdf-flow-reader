# v5「航迹」

状态：产品边界已确认，工程实现尚未开始。

「航迹」不是通用批注或 AI 笔记系统。它是一套服务于心流阅读的情感引擎：读者在被文字触动时，用自由套索留下高清书页片段、关键复述和亲自选择的情绪坐标，然后轻轻回到仍在流动的书中。

## 文档索引

- [`GOAL.md`](./GOAL.md)：目标、完成线与非目标
- [`CONTEXT.md`](./CONTEXT.md)：产品背景、现有基础与术语
- [`DECISIONS.md`](./DECISIONS.md)：已经锁定的产品和技术决定
- [`PLAN.md`](./PLAN.md)：分阶段实施与验收顺序
- [`TODO.md`](./TODO.md)：可执行任务清单
- [`REVIEW.md`](./REVIEW.md)：当前规划复核与后续验收记录

## 一句话产品定义

> 圈住被书触动的一瞬，为它留下一枚情绪坐标，再亲手回到书流。

## 核心循环

```text
有仪式感地载入
→ 自动滚动制造适度挑战与唤醒
→ 档位、背景和希声为身体感受赋予虚构意义
→ 自由套索捕捉被触动的一瞬
→ 截图、情绪坐标与一句复述形成阅读痕迹
→ 手动回流并缓慢重新入流
→ 书架汇总一本书的情绪航迹与合卷后分析
```

当前 v4.0.0 不包含上述 v5 能力。公开首页中的「航迹」内容是路线说明，不是功能承诺。
