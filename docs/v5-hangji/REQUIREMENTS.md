# v5「航迹」冻结需求

状态：**已冻结，等待线性实施**

冻结日期：2026-08-09

事实优先级：本文高于冻结前的叙事性说明；若其他 v5 文档与本文冲突，应先修正文档，不能静默改变实现。

## 1. 北极星

在不把「夜晚的书斋」变成通用批注软件的前提下，为沉浸式 PDF 阅读建立“触动—留痕—回流—回看”循环。

短期的情感回报服务于一件缓慢而长期有益的事：让读者更愿意留在书中，耐心读完一本电子书。

一句话定义：

> 圈住被书触动的一瞬，为它留下一枚情绪坐标，再亲手回到书流。

## 2. 交付路线

先做到在产品所有者自己的 macOS 电脑上稳定运行，再处理 Windows 与 GitHub 公开发布适配；各版本分别验收，后续能力不得阻塞前一版本。

| 版本 | 完成线 |
| --- | --- |
| v4.1 | 独立书架轮播、最近阅读、取书与开书动画，不包含航迹数据 |
| v5.0 | 完整离线“套索—留痕—情绪—回流—回看”闭环 |
| v5.1 | 图文一句复述、系统凭据、本地文件夹与 Obsidian 归档 |
| v5.2 | Zotero 归档、单书分析、全文总结与 LSE Reading Worksheet |
| v5.3 | 多书选择与融贯分析 |

## 3. 不可破坏的产品原则

1. **本地事实先于生成结果。** AI、网络和归档失败不能使用户痕迹消失。
2. **用户控制先于自动化。** 回流必须由用户明确触发，任何手动操作立即取得控制权。
3. **用户情绪与 AI 文字分离。** 模型不得推断、覆盖或伪装成用户感受。
4. **阅读界面保持最小。** 重型分析、模型选择和归档管理只出现在书架。
5. **外部工具只是目的地。** 本地记录是唯一事实源，不做双向同步。
6. **失败必须可见、可恢复。** 不允许静默丢失、无限重试或无提示弱安全降级。

## 4. v5.0 离线核心

### 4.1 显式、一次性的套索

- 点击页面边缘的“丝带环”或按 `L` 进入一次性套索模式。
- 进入后立即暂停自动滚动与 TTS，冻结当前视口。
- 下一次有效指针绘制形成套索，完成或取消后退出套索模式。
- 普通拖动继续用于文字选择，不破坏现有点句朗读。
- `Esc`、右键、过短路径或跨页路径取消本次操作；取消不保存痕迹。
- 取消后保持暂停，不擅自恢复滚动。
- 首次使用只显示一次轻量提示。
- v5.0 只支持同一页面内的套索。

### 4.2 套索闭合即建立草稿

草稿至少保存：

```text
document identity
page index
normalized lasso path
source text and provenance
speed tier and physical speed
reading order and timestamp
crop state
emotion state
```

- 情绪尚未选择也可以回流。
- 裁图失败仍保存路径、文字和上下文，并标记为可重试。
- 系统不得自动把 `(0, 0)` 当作默认情绪。
- 书架明确区分“未落点”“裁图待恢复”和完整痕迹。

建议状态模型：

```text
trace: draft | active | trashed | purged
crop: pending | ready | failed
emotion: unplaced | placed | revised
echo: not-configured | pending | running | completed | unavailable
archive: not-configured | pending | exported | failed | stale
```

### 4.3 可恢复裁图

- 保存覆盖套索范围并带少量上下文边距的高质量矩形原图。
- 永久保存归一化套索路径。
- UI 可以把路径外区域柔和淡出。
- 导出时可以派生透明不规则图或保留上下文矩形图。
- 不把按钮、控制栏或页面外区域写入裁图。
- 裁图异步完成，不能阻塞“回到书流”。

### 4.4 连续情绪坐标

- 横轴：负面效价到正面效价。
- 纵轴：低唤醒到高唤醒。
- 支持点击、拖动、键盘方向键和屏幕阅读器。
- 邻域情绪词只作解释，不作为唯一存储值。
- 模型不得推断或自动填写情绪。
- 首次值保存为 `originalEmotion`；书架中的修正保存为 `currentEmotion`。

### 4.5 显式回流

- 只有“回到书流”或明确恢复播放才启动入流曲线。
- 新书、应用恢复或长时间离开使用约 90 秒曲线。
- 套索、短暂停与短暂回看使用约 30 秒曲线。
- 速度只提高到当前档位的偏高区域，不自动跨档。
- 滚动、调速、暂停、换页、换书或切档立即取消曲线。
- 被取消的曲线不会自行重新启动。

### 4.6 单书航迹

单书详情最终分为“航迹／分析／归档”，但按版本逐步出现，不能提前放置空壳页面：

- v5.0 只显示航迹。
- v5.1 增加回声与归档。
- v5.2 增加分析。

航迹默认显示：

- 效价 × 唤醒散点；
- 按阅读顺序连线；
- 页码、时间和档位筛选；
- 截图、原始情绪、当前情绪与当时状态；
- 点击跳回原书位置。

没有痕迹的书仍显示阅读进度和安静空状态，不生成虚假的情绪图。

### 4.7 修正、归档失效与删除

- 航迹图使用 `currentEmotion`，详情可查看 `originalEmotion`。
- 修改后将外部归档状态标记为 `stale`，不自动改写外部内容。
- 删除先进入本地回收站，默认保留 30 天。
- 彻底删除需要再次确认。

## 5. 文档身份与持久化

### 5.1 内容身份与位置分离

- 同一 PDF 移动、改名或复制后仍属于同一本书。
- 最近路径只是定位信息，内容指纹才是书籍身份。
- 原路径失效时请用户重新定位；验证身份后恢复全部航迹。
- 内容变化的修订版或重新扫描版视为新书。
- v5.0 不根据标题自动合并版本。

具体采用 PDF 内部 fingerprint、流式哈希或组合策略，由大型 PDF PoC 决定，但必须满足上述行为。

### 5.2 可检查文件目录

```text
Application Data/
  documents/<document-id>/
    document.json
    traces/<trace-id>/
      trace.json
      crop.<lossless-format>
      echo.json
      archive.json
  trash/
```

- 使用临时文件、同步落盘和原子改名。
- 用户事实、AI 结果和归档状态物理分离。
- 不引入 SQLite。
- 现有 `localStorage` 只保留普通偏好与阅读位置。
- Electron 桌面版提供完整能力；普通浏览器模式保持基础阅读和开发调试，并隐藏桌面专属能力。

## 6. v5.1 图文回声与基础归档

### 6.1 AI 未配置

- 离线核心完整可用。
- 不弹窗催促配置，不显示持续加载。
- 以安静状态说明“配置后可用”。

### 6.2 Provider

- 第一阶段实现一个 OpenAI-compatible endpoint。
- 快速回声模型与强分析模型分别配置。
- v5.1 不捆绑本地 LLM；本地小模型以后独立 PoC。
- API 密钥只进入系统安全存储；不可用时禁用 AI，不退回明文或无提示弱加密。

### 6.3 一句复述输入

默认输入：

```text
套索裁图 + 圈选文字 + 有界附近上下文
```

- 不上传整页或完整 PDF。
- 首次启用时一次性说明裁图会发送给模型。
- 模型支持视觉时发送图文；不支持时自动降级为纯文字并记录 `text-only`。
- 失败、断网和超时不阻塞保存或回流。
- 待生成状态持久化；不做无限自动重试，书架提供手动重试。

### 6.4 基础归档

顺序为本地文件夹，再到 Obsidian：

- 每本书只有一个主要目的地。
- 更改目的地只影响新痕迹。
- 提供“重新导出全部”。
- 不删除或改写旧目的地内容。
- 导出队列和失败状态持久化；自动重试必须有界。

## 7. v5.2 与 v5.3

### 7.1 Zotero

- Prompt 来源与成果归档是两个独立模块。
- 不读取 Zotero `prefs.js` 或其中凭据。
- 根据 DOI、标题、作者和文件信息推荐候选。
- 最终关联、创建或导入必须由用户确认。
- 不自动创建重复条目。

### 7.2 单书分析

每次由用户选择：

1. **航迹语料，默认**：套索文字、附近上下文和回声。
2. **全文语料，重型任务**：完整提取文本；扫描书全书 OCR 需要再次明确授权。

发送前显示页数、字符量、模型和预计成本或上下文规模。

v5.2 内置 Prompt：分析、全文总结、LSE Reading Worksheet。

v5.3 多书 Prompt：融贯。

删除边界不清的“综合”和“书架复述”表述。

### 7.3 Prompt 分层

- 内置 Prompt 有版本号且只读。
- 用户可以复制修改或新建。
- 用户 Prompt 与内置目录分离，升级不覆盖用户内容。
- Prompt 文件不包含 API 密钥。

## 8. 平台、安全与诊断

- 当前实现优先保证产品所有者本机 macOS 可运行。
- 正式适配平台仍为 macOS Apple Silicon 与 Windows x64。
- Intel macOS 和 Linux 暂无正式安装包。
- v5.0 离线核心不被代码签名阻塞。
- v5.1 必须实测打包后的系统凭据存储；安全存储失败则禁用 AI。
- 现有明文 API 字段在迁移成功后删除。
- 私人 PDF 只在本机验收，不进入 Git；AI 测试默认使用脱敏样本。
- 正式版诊断默认关闭且完全本地，只记录时延、状态转换、取消原因、内存和错误码。
- 诊断不得记录正文、裁图、情绪、密钥或绝对路径，也不得自动上传。

## 9. 验收原则

- 普通文字 PDF、双栏论文、扫描书、旋转页与大型 PDF 均需真实验收。
- v5.0 必须在完全离线时完成“套索—情绪—回流—回看”。
- 现有 PDF 渲染、Range 读取、OCR、六档阅读与希声不得回退。
- 套索反馈不得明显落后于指针；暂停、取消与用户夺回控制必须立即生效。
- 基础元数据必须在离开暂停界面前落盘；裁图不能阻塞回流。
- 精确帧率、P50/P95、裁图时延与内存门槛由 8GB/16GB 目标设备 PoC 产生。
- 最终回流体验由产品所有者通过真实阅读会话验收。

## 10. 非目标

- Acrobat 式高亮、图章、绘图和批注工具箱；
- AI 自动判断用户情绪；
- PDF 内容编辑；
- 跨设备实时同步；
- 协作批注；
- 外部工具双向同步；
- v5.0 中的在线 AI、Zotero 或整书分析；
- 流动阅读界面中的复杂 Prompt、模型选择、续写或写作提升面板。

## 11. 变更控制

以下参数由 PoC 决定，不视为需求未冻结：

- 文档指纹算法；
- 套索采样、平滑和最短路径阈值；
- 裁图边距、无损格式、缩略图和分辨率上限；
- 长暂停分钟阈值、曲线 easing 与档内目标位置；
- 正式性能数值；
- 回声图片尺寸、上下文上限、超时与有界重试次数；
- 未签名包的系统凭据行为；
- Zotero 正式 API 能力；
- 全文 OCR 与长文分析的分块大小。

若 PoC 证明冻结方向不可行，实施必须停在阶段门，记录证据并重新取得产品决定，不能静默替换方案。
