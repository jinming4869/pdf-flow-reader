# v5.1「回声与归档」需求冻结

状态：**已冻结，等待线性实施**（2026-08-16）

基线：v5.0 验收基线 `14dcd46`（含 beta.3 分栏修复与 stage 10 退出门关闭记录）

本文件从 v5.0 已冻结的 `REQUIREMENTS.md` 第 6 节展开，不改动已冻结的 v5.0 范围。

发布策略（2026-08-16 产品所有者决定）：v5 全系列完成后统一打 tag 与 GitHub Release；本版只产出本机验收候选，不单独发布。

## 1. 版本目标

v5.1 交付：

1. 系统凭据；
2. 图文一句复述（`TraceEchoProvider`）；
3. 本地文件夹归档；
4. Obsidian 归档；
5. Prompt 分层（内置只读 / 用户副本）。

北极星不变：**快速回声模型和强分析模型分别配置；本地记录是唯一事实源；外部工具是目的地。**

## 2. 系统凭据

- API 密钥只进入 Electron `safeStorage`（macOS Keychain / Windows Credential Manager）。
- 不可用时禁用 AI，不退回明文、不无提示弱加密、不写入 Prompt 文件。
- 现有明文 API 配置字段在迁移成功后删除，并增加扫描测试。
- 不读取 Zotero `prefs.js` 或其中凭据。
- 打包后必须实测凭据读写；未签名包失败路径先行验证（延续 R9）。
- 凭据从主进程管理，renderer 通过窄 IPC 使用，凭据值不落日志、不进 Git。

## 3. 图文一句复述

输入契约（v5.0 已冻结）：

```text
套索裁图 + 圈选文字 + 有界附近上下文
```

- 不上传整页或完整 PDF。
- 首次启用时一次性说明裁图会发送给模型。
- 模型支持视觉时发送图文；不支持时自动降级纯文字并记录 `text-only`。
- 阶段一实现一个 OpenAI-compatible endpoint；快速回声与强分析分别配置。
- v5.1 不捆绑本地 LLM。
- 失败、断网、超时不阻塞套索保存或回流。
- 待生成状态持久化；不做无限自动重试，书架提供手动重试。
- 目标延迟：P50 < 1.5s、P95 < 3s；不达标则只保留可降级路径。

## 4. 基础归档

顺序：本地文件夹 → Obsidian。

- 每本书只有一个主要目的地。
- 更改目的地只影响新痕迹，不迁移旧痕迹。
- 提供“重新导出全部”。
- 不删除、不改写旧目的地内容。
- 导出队列和失败状态持久化；自动重试必须有界。
- 导出内容：套索裁图、圈选文字、情绪坐标、页码锚点、一句复述（若已生成）。

## 5. Prompt 分层

- 内置 Prompt 版本化且只读。
- 用户复制、修改或新建的 Prompt 独立保存，升级不覆盖。
- Prompt 文件不包含 API 密钥。
- 复杂 Prompt（分析、总结、LSE、融贯）仍属于 v5.2 / v5.3，不在 v5.1 出现。

## 6. 界面

- 单书详情页按版本逐步出现，不能提前放置空壳：v5.1 增加“回声／归档”入口。
- 流动阅读期间只出现一句复述。
- 未配置 AI 时：离线核心完整可用，不弹窗催促，以安静状态说明“配置后可用”。

## 7. 非目标（仍属后续版本）

- Zotero 归档与单书分析：v5.2。
- 多书融贯：v5.3。
- 双向同步、自动清理旧目的地、本地 LLM 捆绑。
- Windows / GitHub 公开发布适配：v5.4（阶段 14）并需单独授权；按 2026-08-16 决策，所有公开 tag / release 延后到全系列验收完成后统一执行。

## 8. 验收门（阶段 11）

- 安全失败降级通过：凭据不可用时 AI 全程静默禁用。
- 图文 / 纯文本回退通过：无视觉模型时 text-only 可完成一句复述。
- 归档恢复通过：导出中断后重试不产生重复文件。
- Node 完整回归、Electron smoke、packaged 实测通过。
- 正式包诊断默认关闭且完全本地，不记录正文、裁图、情绪、密钥或绝对路径。
